### Notes
---
- Corporate armour can only be found in backpacks.
- Loadout code is `awc` for worn armour, `arc` for spare.
- This armour is tougher and more protective than combat armour, as light as garrison armour, and has environmental resistance on par with the radsuit.
- The armour self-heals damage to it over time. The more damaged the armour is, the slower the healing. It only self-heals when worn.
